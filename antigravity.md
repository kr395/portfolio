# Antigravity Aesthetic & Visual Guidelines

**Code:** Gopal Kumar Das Portfolio (KR)
**Style:** Modern, High-Performance 3D Interaction, High-Context Glassmorphism, Deep Cyber-Dark theme with Neon Cyan/Purple accents.

---

## 1. Core Visual Elements

### The Mascot (Robot)
*   **Appearance:** Must always match the character from `image_9.png`: A sleek, pure white, perfectly spherical head and body.
*   **Face:** A black glass screen visor displaying purple LED emoji-style eyes. Must always appear winking or smiling.
*   **Limbs:** Smooth white armor plates with purple LED line accents.
*   **Interactions:** Often shown floating on a circular blue glow platform. One hand is usually waving, the other pointing (to content).

### The Holographic Screen (Journey Panel)
*   **Appearance:** A stylized, translucent glass frame with pink/purple glowing outlines and data paths. Must match the structure in `image_9.png`.
*   **Text/Icons:** "MY JOURNEY" is the title. Specific icons (book, gears, CPU, trophy, rocket) must map to the key timeline nodes: BEGINNINGS, DEVELOPMENT, MILESTONES.
*   **Accents:** Pencils often frame the panel.

## 2. Page Structure & Composition

### Global Aesthetic
*   **Background:** Deep midnight cyan/indigo (#0B0F19) providing high contrast for neon lights.
*   **Anti-Gravity Effects:** Objects must float at varying depth levels (z-index) to enable extreme parallax scrolling and anti-gravity visuals. Objects should have subtle depth reflections.
*   **Cursor Trail:** The user cursor must have a subtle, soft purple/pink particle trail indicating interactivity.

### Typography
*   **Huge Text (e.g., "KR"):** Bold, heavy sans-serif typefaces with architectural structure, sometimes featuring a glass effect (e.g., Syne Extra Bold, Clash Display).
*   **Body Text & Tags:** Minimal, geometric sans-serif (e.g., Plus Jakarta Sans, Geist Sans) for all descriptions, tech tags, and timeline details.

---

## 3. Section Specific Rules

### Hero Section
*   Dominance of the KR logo and the floating mascot. Must look interactive.

### Timeline (Coding Journey)
*   A vertical flow line (electric cyan/purple).
*   Must pass through years (`2022`, `2023`, `2024`). Nodes (points) must glow brightly when "active."
*   GitHub activity screens must look authentic.

### Projects Section
*   Logic over aesthetics: Group into columns by category (e.g., WebApp, Mobile App, AI Tools).
*   Each project card must have small, dedicated tech tags at the bottom, an description, and an external live link icon. Cards must visually respond to cursor depth tilt.
